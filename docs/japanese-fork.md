# 非公式の日本語版

この Fork は [miuuyy/Octopus-SI-OS](https://github.com/miuuyy/Octopus-SI-OS) のデスクトップ UI を日本語で使うためのものです。初回案内、設定、メニュー、ナビゲーション、操作時の案内と日時表記を日本語化しています。現在は日本語を既定の表示とし、言語の切り替えには対応していません。利用者のメッセージや外部サービスから届く内容は翻訳しません。

## 上流への追従

- 更新は、このチャットで依頼されたときに行います。定期的な自動確認や自動反映は行いません。
- `origin` は日本語版 Fork、`upstream` は元のリポジトリです。上流のコードを基準にし、日本語化に必要な差分を保ちます。
- 更新時は `upstream/main` の変更と公式の日本語対応状況を確認します。既存のローカル変更を保護したうえで取り込み、新設・変更された画面の訳文を確認します。
- 関連する型検査・契約テストを実行し、ビルド済みアプリを配布する前に、表示の変更をパッケージ版と専用のテスト用 Home で確認します。実際のアカウントでのログインやモデル応答は、別に検証状況を示します。

## ビルド済みアプリ

公開済みの配布版は [日本語版 0.1.0 Preview 1](https://github.com/SORALNV/Octopus-SI-OS/releases/tag/ja-v0.1.0-preview.1) です。Apple Silicon・macOS 14以降向けで、DMG、チェックサム、インストーラーと [別の Mac に渡すインストール用プロンプト](https://github.com/SORALNV/Octopus-SI-OS/blob/ja-v0.1.0-preview.1/app/release/install-prompt-ja.md) を配布しています。Node・Rust とソースの取得は不要ですが、Command Line Tools for Xcode が必要です。未公証のため、初回起動の準備は Release の説明を確認してください。

現在の `main` は 0.1.1 のソースです。上流への追従と日本語表示の修正をコードとして公開しており、この更新の GitHub Release は公開していません。

`app/release/` にあるインストーラー、プロンプト、Release 説明は、次回の配布候補 `ja-v0.1.1-preview.2` 向けの原稿です。このタグは未公開のため、現在のインストールには上記の公開済み版を使ってください。配布を再開する場合は、最終ソースに合わせてアプリを作成・確認し、`app/scripts/release-macos.cjs` で DMG を生成します。`build-info.json` に検証範囲と基準コミットを記録し、全添付ファイルのチェックサムを照合してから公開します。上流用の `v*` タグのワークフローは使いません。

## 独自対応の終了条件

上流の正式なコードで日本語 UI が利用できるようになったら、この Fork 独自の翻訳対応を終了し、公式版への移行を案内します。Issue・PR・開発予定だけでは対応済みとは判断しません。Fork や作業履歴を自動で削除することはありません。

## 上流への提案

現在の変更は英語の画面文言を日本語に置き換える方式です。上流への貢献として提出する場合は、既存の英語表示を維持できる言語切り替えの仕組みと日本語訳を分けて提案します。Issue・PR の作成は依頼を受けて行います。
