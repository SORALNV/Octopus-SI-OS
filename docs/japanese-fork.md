# 非公式の日本語版

この Fork は [miuuyy/Octopus-SI-OS](https://github.com/miuuyy/Octopus-SI-OS) のデスクトップ UI を日本語で使うためのものです。初回案内、設定、メニュー、ナビゲーション、操作時の案内と日時表記を日本語化しています。現在は日本語を既定の表示とし、言語の切り替えには対応していません。利用者のメッセージや外部サービスから届く内容は翻訳しません。

## 上流への追従

- 更新は、このチャットで依頼されたときに行います。定期的な自動確認や自動反映は行いません。
- `origin` は日本語版 Fork、`upstream` は元のリポジトリです。上流のコードを基準にし、日本語化に必要な差分を保ちます。
- 更新時は `upstream/main` の変更と公式の日本語対応状況を確認します。既存のローカル変更を保護したうえで取り込み、新設・変更された画面の訳文を確認します。
- 関連する型検査・契約テストを実行し、表示の変更はパッケージ版と専用のテスト用 Home で確認してから公開します。実際のアカウントでのログインやモデル応答は、別に検証状況を示します。

## 独自対応の終了条件

上流の正式なコードで日本語 UI が利用できるようになったら、この Fork 独自の翻訳対応を終了し、公式版への移行を案内します。Issue・PR・開発予定だけでは対応済みとは判断しません。Fork や作業履歴を自動で削除することはありません。

## 上流への提案

現在の変更は英語の画面文言を日本語に置き換える方式です。上流への貢献として提出する場合は、既存の英語表示を維持できる言語切り替えの仕組みと日本語訳を分けて提案します。Issue・PR の作成は依頼を受けて行います。

## 初回公開時のビルド確認

初回の日本語化は上流コミット `c44cede` を基準にしています。この時点の上流は、ES2021 以降の API を使うコードに対して `app/tsconfig.json` の `lib` が ES2020 のままです。同じローカルの依存パッケージで比較すると、元のコードと日本語化したコードの両方に型エラーが60件発生しました。

日本語化のローカル検証とアプリの作成では `lib` を ES2023 にした既存のローカル設定を使用しています。日本語化した公開ソースも `--lib DOM,DOM.Iterable,ES2023` を指定した型検査で確認しています。上流由来の設定不足と、既存の依存パッケージ変更は、今回の翻訳差分には含めていません。上流の更新を取り込む際には、この前提が解消されたかも確認します。
